# Repo Locator

Map and table of commercial repositioning and ferry flights.

Rule: an airline ICAO callsign plus exactly four digits starting with 8 or 9. That whole set is treated as a repo, passenger and cargo frames included.

Open `repo-locator.html` in a browser. The map uses CARTO dark tiles, so it needs a network connection. The flight list is a snapshot from adsb.lol at about 21:20 MST on 5 Oct 2026.

Amber is 9xxx, cyan is 8xxx, violet is a cargo frame.
