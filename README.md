# Repo Locator

Map and table of commercial repositioning and ferry flights.

Rule: an airline ICAO callsign plus exactly four digits starting with 8 or 9. That whole set is treated as a repo, passenger and cargo frames included.

The site entry is `index.html` (same page as `repo-locator.html`). Amber is 9xxx, cyan is 8xxx, violet is a cargo frame. Snapshot from adsb.lol at about 21:20 MST on 5 Oct 2026.

## GitHub Pages

On a free account the repo must be public. Then: Settings, Pages, Build and deployment, Deploy from a branch, branch `main`, folder `/ (root)`, Save.
